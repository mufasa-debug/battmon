============================================================
  BATTMON: QUICK SETUP GUIDE (FOR ANY MAC)
============================================================

1. OPEN TERMINAL AT THIS FOLDER:
   • Easy method: Open Terminal, type "cd " (with a space),
     then drag and drop this Battmon folder into Terminal,
     and hit Enter.
   • Or right-click this folder -> Services -> "New Terminal at Folder"

2. RUN INSTALLATION (ONE COPY-PASTE COMMAND):
   chmod +x setup.sh battmon battery_monitor.sh && ./setup.sh

3. CHOOSE SETUP OPTION:
   • Press 1 for Quick Install (Default alerts: 100%, 80%, 10%, 5%, 1%)
   • Press 2 for Custom Setup (Set custom percentages like 67%, 82%)

============================================================
  USAGE (RUN FROM ANY TERMINAL WINDOW AFTER INSTALL)
============================================================

• Open interactive menu:
  battmon

• Test speech & key silencing (Mute / Volume Down / Charger):
  battmon test

• Check battery status & rules:
  battmon status

• View all commands:
  battmon --help

============================================================
  UNINSTALLATION
============================================================

From this folder, run:
  ./setup.sh --uninstall
