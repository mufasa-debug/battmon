BATTMON QUICK SETUP
===================

1. Open Terminal in this Battmon folder.
2. Run:

   chmod +x setup.sh battmon battery_monitor.sh
   ./setup.sh

The installer preserves an existing active configuration, creates a backup,
installs one command (`battmon`), validates the LaunchAgent, and starts the
background monitor.

Install without starting the service:

   ./setup.sh --no-start

Useful commands:

   battmon             Open the interactive manager
   battmon status      Show current state and every alert
   battmon doctor      Run read-only health checks
   battmon test        Test speech and interruption controls
   battmon start       Enable background monitoring
   battmon stop        Stop background monitoring

The default alert pause is 100 ms. The manager accepts values down to 50 ms.

Safe uninstall (configuration preserved):

   ./setup.sh --uninstall

Full removal with a configuration backup:

   ./setup.sh --uninstall --purge
